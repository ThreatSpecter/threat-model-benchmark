# Sources and licences

Everything under `cases/` and `sources/` is collected from public work and reproduced unedited, with the attribution
each licence asks for. The scorer and the prompts are this repository's own.

- **CNCF TAG-Security project assessments** (`cases/design/cncf-*`, `sources/cncf/`): https://github.com/cncf/tag-security,
  `community/assessments/projects/`. Documentation licence CC BY 4.0. See `sources/cncf/NOTICE.md`.
- **OWASP Threat Model Library** (`cases/design/tml-*`, `sources/tml/`): https://github.com/OWASP/www-project-threat-model-library,
  MIT. Six models in OWASP's TMBOM schema. See `sources/tml/NOTICE.md`.
- **AWS Threat Composer** samples (`cases/design/composer-*`): https://github.com/awslabs/threat-composer, Apache 2.0.
- **IETF RFCs** (`cases/design/ietf-*`): the text of the RFCs named in each `meta.json`, reproduced under the IETF Trust's
  legal provisions; the expected threats are the security considerations as written.
- **ACSE-Eval** (`cases/design/acse-*`): Munshi et al., 2025, https://huggingface.co/datasets/ACSE-Eval/ACSE-Eval — 100 AWS
  architectures with diagram, diagram code, CDK and expert threats. The dataset's own licence applies.
- **awslabs/diagram-as-code** examples (`sources/aws/`): https://github.com/awslabs/diagram-as-code, Apache 2.0; see
  `sources/aws/LICENSE` and `sources/aws/NOTICE.md`.
- **GitHub Advisory Database** (`cases/advisories/`): https://github.com/github/advisory-database, CC BY 4.0, plus the
  repositories' own advisories (openfga/openfga, nats-io/nats-server).
- **CyberGym** (`cases/cybergym/sample.json`): a sample of task ids from https://github.com/sunblaze-ucb/cybergym; the
  tasks themselves are fetched from that benchmark.
